SmartTableResizeGesture.h

One column resize, from the press or the button that starts it to whatever ends it.

Source/SmartTables/Public/SmartTableResizeGesture.h

One column resize going on, from whatever starts it to whatever ends it.

Two TYPES and never one struct with a flag: a pointer drag and an intent hold write different fields. A field only the pointer drag measures is a field only the pointer shape carries, so no reader can take a column named with no press behind it for a drag.

Reset writes a whole fresh value. A field added to any shape above clears itself, with no list of clears for it to be left out of.

Not a USTRUCT, since nothing here is authored, saved or reached from Blueprint.

StartWidths
TMap< FName, float > StartWidths

The width of every shown column as this gesture first found it.

A drag is measured against this snapshot, never against the widths in force this frame. A neighbour moves exactly as far as the drag moved, and a drag out and back lands where it started.

Keyed by name and never by number. Hide a column part way through a hold and a number would point at its neighbour. It sits outside the three shapes, and it has to: the SHeaderRow sizing grip settles a width without ever saying a gesture began, and this fills up while nothing is resizing.

FSmartTablePointerResize struct

A pointer is dragging a column edge.

HandleHeaderRowMouseDown builds every one of these, and it is the one place a press is measured. Every field below is written there, so a gesture in this shape can be read for all of them with no test for whether anything ever wrote them.
