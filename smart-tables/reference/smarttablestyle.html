SmartTableStyle.h

One asset carrying every brush and text style a table wears.

Source/SmartTables/Public/SmartTableStyle.h

What a table looks like, in one asset.

Every field here sits on USmartTable as well, which is fine for one table and wrong for twenty. An asset set on a table covers the table's own values while it is set, and clearing the asset puts them back. A table with no asset carries on with what its Details panel says.

The class defaults are also the look a table opens with. The constructor builds most fields from the palette in Project Settings, and USmartTable copies the lot. A default FSlateBrush is a solid white box and not an empty one, so a field the constructor skipped would draw white over whatever is under it.

BuildDefaultsFromSettings
void BuildDefaultsFromSettings()

Builds the whole look out of the palette in Project Settings. The constructor is one call to this.

Public so a palette edit can run it again on the class defaults, which is what puts a colour change on screen without opening the editor again. Nothing runs it on an asset: that would throw away every field the asset was authored with.

FSmartTableMenuStyle struct

What the header menu looks like, and the row menu with it.

A menu draws in a window of its own, over whatever is under it, the table included. Its background has to be solid, or what is behind shows through. One step off the table's own too, so the two read as two surfaces and not as one with a seam down it.

Only the parts a skin has a view about are here. Every other Menu key falls through to the engine's own style, so a key a later engine adds goes on drawing instead of turning into a missing texture box.

FSmartTableSearchHighlight struct

How a menu marks the letters of an entry that match its search.

The mark is a fill and an outline, each switched on its own. Both take the colour of the label text and draw see through. That colour already reads against the menu. The background shows through the mark, a hovered entry included. Each part draws lighter while the other is on.

A label colour set to Inherit has no colour of its own to take. The HighlightShape of the label style draws then instead.
