SmartTableDeadSecondaries.h

The columns a second sort level can't move a row with, worked out only when something asks.

Source/SmartTables/Public/SmartTableDeadSecondaries.h

Columns a second sort level could not reorder, and whether that answer still fits the rows.

Worked out when asked for, not at sort time. Filling it costs a pass over the presented rows, and the only things that read it are a Shift held header and an open menu, so most tables pay nothing.

MarkStale
void MarkStale()

Says the answer may no longer fit the rows. Every input it depends on, and where the table marks it:

  • the presented order and the row set, ties being groups in it. HandlePresentationChanged.
  • the values, which decide what ties. The same place, through bCellsStale.
  • the declared columns, the candidates. SetColumns.
  • bAllowDeadSecondarySort, which decides if it is worked out at all. Its setter.
  • the model, whose swap arrives as a presentation change.

One row changing is left out. It can move the answer, but marking on it left a live feed paying a whole-table pass per tick. The gated readers only draw, and SortBySecondaryColumn works it out again.
